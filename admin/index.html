Accés amb Google

Entra amb el compte voluntarisgrupbarna@gmail.com per gestionar els partits, els resultats i els cartells del club.

⚙️ Falta connectar Google (5 minuts, un sol cop)

  1. Entra a console.cloud.google.com/apis/credentials amb el compte voluntarisgrupbarna@gmail.com.
  2. Crear credencials → ID de client d'OAuth → Tipus: Aplicació web.
  3. A "Orígens autoritzats de JavaScript" afegeix-hi https://cbgrupbarna.info i https://www.cbgrupbarna.info.
  4. Copia l'ID que acaba en .apps.googleusercontent.com.
  5. A GitHub, obre admin/config.js, enganxa'l a GOOGLE_CLIENT_ID i desa. Ja funciona.
