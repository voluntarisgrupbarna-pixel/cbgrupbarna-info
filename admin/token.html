GUARDAR EL TOKEN UNA SOLA VEGADA

El token es guarda xifrat amb la contrasenya del club dins del repositori (admin/token.enc.json). A partir de llavors, entrar la contrasenya a qualsevol dispositiu ja el recupera sol: no cal tornar-lo a enganxar mai més a la galeria, als partits ni enlloc.

GUARDAR O CANVIAR EL TOKEN

Millor un token fine-grained limitat només a aquest repositori amb permís Contents: Read and write: si mai es filtrés, només afectaria la web, no tot el compte. Es crea a github.com/settings/personal-access-tokens. Qui tingui la contrasenya del club pot recuperar el token: si canvies la contrasenya, torna a guardar-lo aquí.

TREURE'L DEL REPOSITORI

Esborra admin/token.enc.json. Cada dispositiu tornarà a demanar el token com abans.
