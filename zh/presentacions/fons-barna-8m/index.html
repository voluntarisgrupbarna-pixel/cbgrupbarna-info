公开信

巴塞罗那,2026年3月4日

· 主题:CB Grup Barna / 2026年三八妇女节 / FCBQ女子篮球计划

尊敬的FCBQ主席:

CB Grup Barna是一家1965年创立于巴塞罗那Sant Martí区El Clot社区的青训篮球俱乐部。 在连续61年的发展历程中,我们建立了加泰罗尼亚最先进的女子篮球投入模式之一: 我们50%的预算投入女子项目,而行业惯例约为35%。

值此国际妇女节（2026年三八妇女节）之际,我们向您和FCBQ理事会提出一个影响加泰罗尼亚数百名年轻女性的 结构性问题,并提出一种可以扭转这一局面的俱乐部-联合会合作模式。

我们拥有38位在职女教练,她们每周培养球员,打破刻板印象,支撑着我们的模式运转。 然而她们之中没有一人持有联合会执教资格证——并非能力不足,而是受限于成本与时间。 在FCBQ的统计数据中,她们根本不存在。

我们恳请加泰罗尼亚篮球联合会正式认可她们,并协助她们完成这一步。这不是一项支出, 而是一项在性别平等、技术培养以及加泰罗尼亚青训女子篮球根基稳固性方面能带来直接、可衡量回报的投资。

此致敬礼,
CB Grup Barna

· 一家取得高水平女子竞技成绩的社区俱乐部

35支球队中有20支是女子队

俱乐部共有35至38支球队,注册成员超过450人,提供从预幼儿组到成年组不间断的完整梯队。 57%的梯队体系为女子项目:35支球队中有20支女子队。

成年女子队参加Supercopa Femenina及Copa Catalunya联赛,成绩甚至超过男子队—— 投入与成绩成正比。而这一切都是在没有自有场馆、也没有专项市政补贴的情况下取得的。

人才输出至LF2联赛:在Barna培养的球员已加盟Almeda及UE Mataró俱乐部。

加泰罗尼亚篮球面临一个 注册人数数据无法体现的挑战:女性以球员身份加入篮球运动,却没有留在技术和领导岗位上。

在全国范围内,2024年女性注册 人数达157,432人,占总数的35.7%,女性增长速度是男性的两倍（新增19,165名女性对比9,377名男性）。 但存在一个系统性瓶颈:越来越多的女性进入篮球运动,但将她们转化为教练的机制并未同步跟进—— 这并非缺乏才能,而是缺乏资源、时间和认可。

· FCBQ导师计划的悖论

为已经解决问题的人设计

要参与该计划,女教练必须持有0级、1级、2级或更高级别的资格证。 这个本应为未职业化教练提供机会的计划,恰恰排除了那些还未能实现职业化的教练。

· Barna方法论

这套体系一直缺少的名字

「Barna方法论」不是一份文件,也不是一个项目。它是俱乐部61年来一直在做,却从未被归纳成 可输出体系的那个名字。

  • ①反向投入——俱乐部将50%的预算投入女子篮球:这一战略性投入迫使女子项目 必须保持高质量。投入创造期待,期待创造水平,水平创造榜样。
  • ②培养路径——球员停止打球后不会离开俱乐部:她们转型为教练,许多人执教男子队。 这个循环（幼儿班→青训→竞技→技术团队）正是让俱乐部「培养女性领导力」而不仅仅是「拥有女子球队」的关键。
  • ③社群效应——社交媒体上以女性为主的受众并非某次推广活动的结果, 而是前两项原则自然产生的后果。

没有名字,「Barna方法论」就是隐形的。一个名字能将零散的实践转化为体系, 将体系转化为方法论,将方法论转化为机构与传播资产。有了明确的概念,俱乐部面对FCBQ、市政府、 加泰罗尼亚自治政府、西班牙篮协（FEB）等机构时,就不再只是「一家做得不错的俱乐部」, 而是「一套可复制模式的创造者」。

四、隐藏的模式:女性人才的恶性循环

FCBQ数据 + 流失研究 + 俱乐部内部实况交叉分析

将FCBQ数据、球员流失研究 与CB Grup Barna内部实况进行交叉分析,可以归纳出将女性排挤出篮球运动的机制:

  1. 1球员在13至16岁期间停止参赛。
  2. 2在技术岗位上找不到女性榜样 → 从未考虑过执教。
  3. 3若想执教:需要取得资格证（0级课程:金钱成本+时间成本+占用周末）。
  4. 4没有资格证,就无法参加FCBQ导师计划。
  5. 5没有导师指导,放弃职业化的想法。
  6. 6所在青训梯队依然缺少可参照的女教练。
→ 13岁的女孩看不到未来 → 回到第1步

CB Grup Barna通过吸纳退役球员担任教练,部分打破了这一循环。但由于没有资格证, 这条培养路径对联合会体系及其统计数据而言是不可见的。

CB Grup Barna的提案是:不要求先取得资格证才能获得支持, 而是提供支持帮助她们取得资格证。

体系看不见的人才

直接影响：她们覆盖10至16岁年龄段的梯队,这正是女性榜样影响最关键的阶段。

当FCBQ公布加泰罗尼亚持证女教练的统计数据时,CB Grup Barna的38位女教练并不在其中。 不是因为她们不存在,而是因为她们没有资格证。加泰罗尼亚公布的女性技术岗位数据低于实际情况。 体育政策正是基于不完整的数据制定的。

六、提案方案:Fons Barna 8M

女教练奖学金 · 三个行动层面

这不是一次性的诉求, 而是一套旨在弥合资格认证鸿沟、并能在全加泰罗尼亚复制推广的俱乐部-联合会合作模式, 以推动系统性变革。

第一层 · 即时行动

资格认证奖学金基金

每位女教练的单位成本（FCBQ 0级课程）,具体金额待共同商定。

  • 优先对象:在职、无事先资格认证的女教练
  • 建议联合资助方案:俱乐部30% + FCBQ 70%（小型俱乐部可由FCBQ承担100%）
  • 留任承诺:受益俱乐部至少留任2个赛季
  • CB Grup Barna:38位可立即申请的候选人
第二层 · 6个月

重新设计FCBQ导师计划

修改准入标准:从「事先持证」改为「在注册俱乐部中担任在职教练」。

  • 以实际执教活动而非事先认证作为准入途径
  • 不需要大量经济投入
  • 仅需联合会的一项政策决定
第三层 · 1年

「从El Clot到全加泰罗尼亚」试点项目

将CB Grup Barna模式转化为经过记录、可复制推广的试点项目。

  • 获FCBQ认证为「女子技术培养标杆俱乐部」
  • 向巴塞罗那市政府与加泰罗尼亚体育委员会汇报
  • 成果报告,作为未来联合会政策的依据

· 三句话总结

  • ①设立FCBQ奖学金基金,为已在工作的38位女教练支付资格认证费用。 投入即可获得立即回报:38位新增持证技术人员。
  • ②改变导师计划的准入标准:从「已持证者」改为「正在执教者」。
  • ③将CB Grup Barna模式打造为全加泰罗尼亚所有社区俱乐部都可复制的政策。

七、为何此刻刻不容缓

与三八妇女节真正意义的关联

三八妇女节不只是俱乐部 发布一张紫色背景帖子的日子,而是每年提醒我们结构性不平等依然存在的时刻——它要求的是结构性行动, 而非象征性姿态。

· 巴塞罗那,女子篮球之都

宏观背景

巴塞罗那是欧洲主要城市中唯一没有女子精英联赛球队的首府。这座城市拥有加泰罗尼亚最大的青训基础, 但向国家级联赛的转化率却最低。

将女教练职业化,是扭转这一反常现象的必要条件。

· 面向FCBQ与加泰罗尼亚青训篮球的可复制性

CB Grup Barna模式适用于任何愿意投入女子项目、拥有完整梯队体系、并有退役球员愿意转型为 教练的加泰罗尼亚青训俱乐部。可复制俱乐部的特征如下:

  • 150–500名注册成员,10–25支在役球队
  • 各梯队均有显著的女性代表性
  • 有与俱乐部有渊源、愿意执教的退役球员
  • 有优先发展女子篮球的机构意愿

联合会的角色是独一无二的:建立规范框架与资金基础。 没有FCBQ的支持,CB Grup Barna模式只是一个个案;有了FCBQ的支持, 它可以成为加泰罗尼亚青训女子篮球的新标准。

九、结语与向FCBQ提出的正式提案

她们已在执教。体系必须认可她们。

CB Grup Barna在El Clot 社区用61年时间,建成了许多体育政策试图在4年内创造的东西:一个女性不会离开篮球运动的生态系统。 但我们是在没有资格证、没有注册记录、没有机构可见度的情况下做到这一切的。

CB Grup Barna的38位女教练 真实存在。她们在工作。她们培养球员。她们执教男子队,打破刻板印象。她们降低了球员流失率。 但在FCBQ的统计数据中,她们并不存在。

· 向加泰罗尼亚篮球联合会提出的正式提案

  1. 请FCBQ设立奖学金基金,用于资助在职、无资格证的女教练取得认证, 初期资金用于覆盖0级体育技术员课程,采用俱乐部-联合会联合资助模式 （建议方案:俱乐部30% / FCBQ 70%,小型俱乐部由FCBQ承担100%）。
  2. 请女教练导师计划修改准入标准,纳入在职但无事先资格认证的女教练, 将「事先持证」要求改为在注册俱乐部中真实、可核实的执教活动。
  3. 请让CB Grup Barna担任该模式的试点记录俱乐部,以便其他加泰罗尼亚俱乐部 复制推广,并获FCBQ认证为「女子技术培养标杆俱乐部」。
  4. 请FCBQ建立过渡期培训中女教练登记制度,以统计真实存在的女性技术人才, 并编制真正反映加泰罗尼亚女子篮球实况的统计数据。
