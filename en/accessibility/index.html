Accessibility statement

Everyone should be able to use this site: with a screen reader, with the keyboard alone, with the text enlarged, or without telling colours apart. Here is where we stand, what is still missing, and how to let us know.

Last updated · 2026-08-24

The commitment

CB Grup Barna wants cbgrupbarna.info to work with any way of reading and navigating: with a screen reader, with the keyboard alone, with the text enlarged, with the phone rotated, without telling colours apart, or with nothing moving on screen. This is a neighbourhood club and the website is the front door: if the door does not open, the person does not come in.

Our reference is the Web Content Accessibility Guidelines (WCAG) 2.2, level AA, which is also what the European standard EN 301 549 and the Spanish Royal Decree 1112/2018 ask for.

Conformance status

This website is partially conformant with WCAG 2.2 level AA: most of the site meets it, with the exceptions listed below. We put it that way because it is the truth: claiming full conformance without having checked page by page would be easy and false.

What has been done

  • Skip to content. On every page, the first thing the keyboard finds is a link that skips the menu and goes straight to the content.
  • Meaningful structure. Every page has a main content region, a top-level heading and headings in order, so a screen reader can build an outline of it.
  • Visible focus. Anyone tabbing through can always see where they are: a thick red outline that stands out on paper, on photography and on dark backgrounds.
  • Labelled forms. Every field has a name the screen reader announces, not just grey text that disappears as soon as you start typing.
  • Checked contrast. The club red (#E20613) gives 4.92:1 on white and the secondary grey 5.74:1, both above the level AA minimum.
  • No data told apart by colour alone. In charts and results, colour always comes with the number or the label.
  • Reduced motion. If your device is set to reduce motion, nothing here moves.
  • Text that scales. Nothing blocks browser zoom or locks the text size.
  • Images with alternative text and videos with the browser's own controls, never autoplaying with sound.
  • Three languages — Catalan, Spanish and English — declared in the code, so the screen reader pronounces each page in the right voice.

What is not accessible yet

These are the barriers we know about. They are not excuses: they are the to-do list.

  • Some PDFs are missing the full tag tree (reading order, headings): the press briefing, the Escoleta fact sheet and the Women and Sport Award candidacy already have one; the club presentation, the sponsorship dossier and "The Barna with data" do not yet, as they are exports from a design tool. All of them carry the correct title and language so a screen reader announces them properly, and the download link states the name, page count and size, not just "PDF". The information in them is always available as HTML on the same page or a nearby one; if you need one in another format, ask and we will send it.
  • Per-team calendars as images are generated automatically. The accessible alternative is the same information as text on each team's page, plus the .ics file to subscribe from a phone.
  • Embedded Instagram videos are served by Instagram in their own player: the club controls neither their captions nor their markup.
  • The video on the reviews page is not an issue today: none is published yet, it is a prepared, switched-off feature. Once it is turned on, the code already requires a captions file before the video can show at all.
  • The poster and print-material pages, built to generate an image rather than to be read, do not meet level AA.
  • The photo gallery is a separate application and has not yet had the same review as the rest of the site.

If you hit a barrier

Write to marqueting@cbgrupbarna.info or 698 42 51 53, and tell us which page it was and what you could not do. We answer within 24 hours and, if it has a quick fix, we fix it the same day. If what you need is a specific piece of content in another format — plain text, large print, over the phone — ask for that too: we will do it.

This statement is live work and will be updated as the points above are closed.
