Migrar àlbums de Flickr

Importa tots els àlbums del compte Flickr del club a la galeria del web. Les fotos es mantenen allotjades a Flickr i es mostren aquí.

1 Clau API de Flickr (gratuïta)

Necessites una clau API de Flickr gratuïta.
Com obtenir-la (2 minuts):
1. Ves a flickr.com/services/apps/create/apply
2. Clica "Apply for a non-commercial key"
3. Omple el nom (ex: "CB Grup Barna Galeria") i la descripció
4. Copia la Key (no el Secret) i enganxa-la aquí
