# Eje: Formatos de contenido novedosos

Principio: el contenido es el motor del funnel del club. Ganar no es publicar más,
es publicar **formatos que el entorno aún no usa** y convertirlos en series
reconocibles. Coordina con `disseny-estetic-club` (criterio visual) y
`video-club-cbgb` (ejecución de vídeo).

## Cómo pensar un formato nuevo

Un formato es un **molde repetible**, no una pieza suelta. Bueno si:

- Tiene un patrón claro (misma estructura, cambia el protagonista/tema).
- Se reconoce como Barna sin ver el logo.
- Encaja en un nivel del funnel (atracción / conexión / conversión).
- Se puede producir de forma sostenible cada semana (si quema al equipo, no sirve).

## Territorios para experimentar

- **Narrativa de jugador/a:** del "resultado del partido" al "viaje de la persona"
  (progreso, esfuerzo, historia). Pilar formativo en formato emocional.
- **Behind the scenes:** vestuario, viajes, calentamiento. Construye comunidad y
  marca mejor que el marcador final.
- **Datos como contenido:** una estadística bien contada (minutos, mejora, paridad
  real del club) puede ser un formato propio.
- **Series episódicas:** seguir a un equipo o a una jugadora durante una temporada.
- **Contenido participativo:** que familias y jugadores generen y compartan.
- **Cross-formato:** lo mismo contado para IG (reel), web (artículo) y evento
  (pantalla), maximizando cada captura.

## Método de experimentación

1. Una hipótesis por formato ("los player features de progreso retienen mejor").
2. Producir 2-3 piezas, no una (un formato se juzga como serie).
3. Medir: guardados, compartidos, comentarios, mensajes a privado (no solo likes).
4. Si funciona → entra al sistema y se versiona. Si no → se aprende y se rota.

## Filtro Barna

- ¿Engancha en los 2 primeros segundos? (reel)
- ¿Tiene protagonista humano identificable?
- ¿Refuerza "formativo + élite" y la paridad real?
- ¿Es reutilizable como serie o es un one-shot?

## Ángulos novedosos típicos de este eje

- Proponer convertir una pieza puntual en una **serie** con nombre propio.
- Traer un formato de otro medio/sector al contenido del club.
- Reempaquetar contenido existente en un formato nuevo (mismo material, más alcance).
