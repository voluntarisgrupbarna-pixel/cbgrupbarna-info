# Instrucciones del proyecto

## Skills — aplicar siempre

Antes de responder cualquier tarea, consulta la lista de skills disponibles y aplica la más relevante sin esperar a que te lo pidan explícitamente.

Reglas de activación automática:

- **Cualquier gráfico, dashboard o visualización de datos** → usar `dataviz` antes de escribir código de gráficos
- **Diseño visual, poster, slide, flyer, presentación** → usar `artifact-design` o `create_visual_design_express_skill`
- **Investigación en profundidad, informe multi-fuente** → usar `deep-research`
- **Cambio de código no trivial** → usar `verify` al finalizar para comprobar que funciona
- **Revisión del diff actual** → usar `code-review`
- **Simplificación o limpieza de código** → usar `simplify`
- **Consultas sobre la API de Claude / Anthropic SDK / modelos / precios** → usar `claude-api` antes de responder
- **Arrancar o mostrar la app en ejecución** → usar `run`
- **Configurar hooks, permisos, settings.json** → usar `update-config`
- **Revisar un PR de GitHub** → usar `review`
- **Revisión de seguridad** → usar `security-review`
- **Inicializar documentación del proyecto** → usar `init`
- **Tarea recurrente o polling** → usar `loop`
- **Configurar atajos de teclado** → usar `keybindings-help`
- **Configurar el hook de inicio de sesión** → usar `session-start-hook`
- **Reducir prompts de permisos repetitivos** → usar `fewer-permission-prompts`

No esperes a que el usuario invoque `/skill-name` — actívalas tú proactivamente cuando el contexto lo justifique.
